# Upstream divergence allowlist
#
# Every upstream file that FakeKernelSU deliberately modifies (M) or removes
# (D) must be listed here. tools/verify-divergence.ps1 fails the build when an
# upstream file is changed or deleted without being listed here, which keeps
# the fork's merge surface with tiann/KernelSU explicit and reviewable.
#
# Format:  <M|D>  <path>  #  <reason>
#
# The reference is upstream tiann/KernelSU, subtree "manager/". The fork's
# repository root maps 1:1 onto that subtree, so the paths below are the
# upstream paths.
#
# Rule of thumb for adding an entry:
#   - prefer a fork-only file over an upstream edit; if you must edit an
#     upstream file, keep the edit as small as possible.
#   - if the edit is a generic improvement that upstream would accept, open
#     an upstream PR and note the PR number in the reason.
