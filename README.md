# FakeKernelSU

> 基于官方 [KernelSU](https://github.com/tiann/KernelSU) 管理器界面做的 **纯演示 / 娱乐版**。
> 长得像、点起来像，但**不碰你的内核、拿不到任何真实 root 权限**。
> 适合拍照、录屏、讲解 Root 原理、做 UI 二次创作。

---

## ⚠️ 先看这里

| | |
|---|---|
| 会不会改内核 | **不会**。整个 APK 里没有一个自带 `.so`，没有 ioctl，没有分区写入 |
| 会不会有真 root | **不会**。所有"授权"只是 App 内部的一个标记文件 |
| 会不会重启手机 | **不会**。`reboot()` 被永久改成空操作 |
| 数据存在哪 | 只在 App 私有目录 `Android/data/com.fake.kernelsu/files/adb/`，卸载 App 即彻底清除 |
| 会不会写 `/data/adb` | **不会** |

> 请勿用它绕过任何设备的安全机制。使用者需自行遵守所在地法律法规。

## 一、它能演示什么

- **完整的安装流程**：进入安装页 → 选「直接安装」→ 播放一段高度逼真的 ksud 刷写日志
  （检测设备 / 修补内核 / 刷写 boot / 安装 ksud）→ 写入"已安装"标记 → 回首页显示**工作中**。
- **超级用户授权**：超级用户页可主动弹出高仿 root 授权框（允许 / 拒绝 / 记住），授权结果会挂到应用头像上。
- **模块管理**：装模块 ZIP 会真的解压，可启用 / 禁用 / 卸载（卸载需"重启"生效，跟真机一个脾气）。
- **su 日志**：授权事件按官方 `sulog` 格式写进本地日志，可在 App 内查看。
- **几乎所有内容都能改**：机型、内核版本、指纹、应用名、桌面图标名、版本号、安装状态、root 可用性……

## 二、两套界面，同一个安装包，自己挑

本 App **完整保留了 KernelSU 的两套皮肤**，装一个包就有两种风格，设置里一键切换。

| 皮肤 | 风格 | 适合谁 |
|---|---|---|
| **Material** | Material 3 动态取色，圆角卡片 | 喜欢 Google 设计语言、想要现代简洁感 |
| **Miuix** | 类 MIUI / HyperOS 的圆润毛玻璃 | 喜欢国产 ROM 观感、想要毛玻璃质感 |

**切换路径**：`设置` → `UI 模式` → 选 `Material` 或 `Miuix`，立即生效并记住。

> 两套界面的**功能完全一致**（控制面板、模拟 su 请求都有），只是长得不一样。
> 装同一个包就行，不用纠结二选一。

## 三、控制面板：把演示内容全改成你想要的

`设置` → **`FakeKernelSU 实验室`**

| 可调项 | 说明 |
|---|---|
| 安装状态 | 跟随实际 / 已安装 / 未安装 / 不支持 |
| Root 可用性 | 关掉之后首页会显示**"已安装，但顶部红字提示 root 获取失败"**的混合状态 |
| 管理器版本号 | 随便填，默认 13000 |
| LKM 模式 | 无 / GKI / LKM |
| 首页机型 | 留空 = 显示你真机的真实机型 |
| 内核版本 / 指纹 | 同上，留空用真机真实值 |
| 应用内名称 | 首页标题、设置页显示的名字 |
| 桌面图标名称 | 4 种预设：`FakeKernelSU` / `KernelSU` / `KSU Manager` / `KSU` |
| 模拟 su 请求模式 | 每次都让你选应用 / 随机弹一个应用 |
| 危险区 | 重置演示状态 / 一键清除全部数据 |

### 隐藏入口：把入口藏起来

实验室本身**不会被删除**，只是可以在实验室里把设置页的入口藏起来。

打开控制面板里的 **隐藏入口** 后：

1. 会先弹一次提示：入口会从设置里消失，**长按首页标题**即可重新进入；
2. 确认后 `设置` 里的实验室入口**自动消失**；
3. 之后想回来 → **长按首页标题**（约 0.5 秒，有振动反馈），两套皮肤都支持；
4. 再进实验室关掉 **隐藏入口**，设置页入口立刻恢复（无需重启）。

适合现场演示、录屏、或者不想让别人一眼看出是模拟版。

## 四、第一次这么玩

1. 打开 App → 首页显示 **未安装**（就算你手机不是 GKI 内核也照样显示"未安装"，官方那个"不支持"的坑已经修掉了）。
2. 点 **安装** → 简易安装页 → 选 **直接安装** → 看刷写日志 → 提示完成。
3. 回首页 → 状态卡显示 **工作中**，版本号是模拟值。
4. 想体验授权弹窗 → 切到 **超级用户** 页 → 列表顶部 **模拟 su 请求** → 选一个应用 → 允许 / 拒绝。
   选「允许 + 记住」后该应用会挂上 **ROOT** 徽标，并写进 su 日志。
5. 想看模块 → **模块** 页装个 ZIP 试试，禁用 / 卸载都能玩。

## 五、卸载的两种语义

- **临时卸载**：只清掉"已安装"标记，演示数据（模块、授权、日志）保留。
- **永久卸载**：清标记 + 把 App 私有目录下的演示数据一起删干净。

## 六、常见问题

**Q：真的不会给我 root 吗？**
不会。这个 App 根本没有 native 库，也没有任何提权逻辑。授权弹窗只是画给你看的。

**Q：会不会偷偷联网、偷偷上传？**
不会。演示逻辑全部是本地文件读写，没有网络请求。

**Q：为什么桌面图标名字变了？**
这是控制面板的"桌面图标名称"功能，用 Android 的 `activity-alias` 动态切换实现的，
四个名字都是同一个 App，只是桌面上显示不同。

**Q：怎么彻底删干净？**
直接卸载 App。数据都在它的私有目录里，卸载即消失。

**Q：能改成别的包名 / 名字吗？**
可以，编译期参数在 `gradle.properties`（`KSU_PACKAGE_NAME` / `KSU_NAME`），详见 `docs/开发指南.md`。
